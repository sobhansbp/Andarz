# مجموعه شهید اندرزگو

نمونه محلی سایت فارسی، خبرها و رزرو رویداد با پایگاه داده SQLite و بدون وابستگی خارجی پایتون.

## اجرا

```bash
cd /workspace/andarzgoo
DEV_MODE=1 SECRET_KEY='a-long-random-local-secret' ADMIN_PASSWORD='choose-a-password' python3 app.py
```

نشانی: http://127.0.0.1:8000 — پنل: `/admin`. در حالت توسعه بدون تنظیم کاوه‌نگار، کد آزمایشی در صفحه نمایش داده می‌شود. داده‌ها در `site.db` ذخیره می‌شوند.

برای اتصال واقعی، `KAVENEGAR_API_KEY` و `KAVENEGAR_TEMPLATE` را به‌صورت متغیر محیطی محرمانه تنظیم کنید و `DEV_MODE` را غیرفعال کنید. الگوی تأییدشده کاوه‌نگار باید متغیر token داشته باشد. کد بدون سرویس پیامکی فعال ثبت‌نام واقعی را نمی‌پذیرد. رمز مدیریت و SECRET_KEY قوی و تصادفی لازم است.

این نسخه یک سرور محلی Python/SQLite است و مستقیماً روی Cloudflare Workers قابل اجرا نیست. پیش از انتشار باید به معماری Cloudflare Workers و D1 منتقل شود، امنیت و محدودیت درخواست‌ها تقویت، HTTPS و پشتیبان‌گیری تنظیم، و سرویس پیامک به‌طور واقعی آزمایش شود. قابلیت ویرایش خبر و رویداد، آپلود تصویر، تقویم شمسی، صدور QR و مدیریت جامع بازه‌ها هنوز پیاده نشده‌اند. داده‌های نمونه در سایت خبر یا رویداد واقعی قلمداد نمی‌شوند.
